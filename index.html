    Shortcuts & help

    / or Ctrl+K
    Focus search
    N
    New card in the first list
    L
    Add a new list
    Ctrl+Z
    Undo last delete / clear / reset
    Esc
    Close dialogs, cancel composers

    Everything is stored locally in your browser (localStorage) — nothing leaves this computer. Use Export in the toolbar to keep a backup or move the board elsewhere. Click the folder icon to connect a board file (e.g. on a shared folder): every change is then saved there automatically, and the connection survives restarts — just reopen this page. In browsers that cannot write files directly (such as Brave), the folder icon loads a board file read-only instead — use Export to save changes back to it.
